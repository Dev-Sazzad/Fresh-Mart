# Scalable E-Commerce Platform (Monorepo)

A production-grade e-commerce monorepo application featuring a distinct REST API backend and a modular Admin Dashboard interface.

## Tech Stack
- **Backend:** Node.js, Express 5, Sequelize ORM, MySQL, JWT Authentication, RBAC
- **Frontend:** React 17, Redux, React-Bootstrap[cite: 15]
- **Architecture:** Monorepo with `npm workspaces`
